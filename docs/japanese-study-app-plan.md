# 일본어 입문부터 JLPT N3 이후까지: 학습 앱 기획안

작성일: 2026-10-01  
상태: 기획 초안. 첫 자격 목표는 JLPT N3이며, 이후 N2를 거쳐 N1까지 확장할 수 있게 설계한다. 첫 APK부터 실제 서비스 구조를 갖춘다.
기술 선택 기록: [TECH_STACK.md](TECH_STACK.md)

## 1. 목표와 사용자

- 일본어를 처음 배우는 사람이 문자부터 시작해 JLPT 각 수준을 순서대로 학습한다. 첫 자격 목표는 N3이며, 이후 N2와 N1 수준까지 추가할 수 있다.
- 어려운 용어를 전제로 하지 않는다. 어휘·문법·독해·청해가 무엇인지부터 설명한다.
- 일본어 문장마다 뜻, 읽는 법, 음성, 단어별 설명을 제공한다.
- 한글 발음은 읽기 보조 수단으로 제공하며 기본적으로 숨긴다. 누르면 표시하고 다시 누르면 숨긴다.
- 첫 배포는 본인 안드로이드폰에 APK로 설치해 사용한다. 첫 진입 화면에서 로그인 없이 시작할 수 있고, 설정에서 계정을 연결한다. 설치 경로와 관계없이 첫 APK부터 서버 DB, 실제 로그인, 관리자 게시, API, 오프라인 저장과 동기화가 동작해야 한다.
- 앱스토어 배포와 아이폰 지원은 별도 검토한다. 인터넷이 없을 때도 내려받은 콘텐츠와 학습 기록으로 공부할 수 있게 한다.

JLPT N3의 시험 구성은 어휘, 문법·독해, 청해다. 먼저 입문부터 N3까지 학습 경로를 만들고, 이후 N2와 N1의 학습 경로와 문제를 순서대로 추가할 수 있다. 시험 문제만 풀게 하지 않고 단계별 개념 설명을 포함한다. [JLPT 공식 시험 구성](https://www.jlpt.jp/e/guideline/testsections.html)

## 2. 학습 흐름과 화면

학습 경로: JLPT와 공부 영역 소개 → 히라가나·가타카나와 발음 → 기초 문장 → N5 수준 → N4 수준 → N3 대비 → N3 모의 연습 → 이후 N2, N1 순서로 확장 가능.

등급은 화면이나 데이터베이스의 고정된 `N3` 칸으로 표현하지 않는다. 등급별 과정·수업·문제에 공통된 구조와 고유 ID를 부여해 새 등급을 콘텐츠로 추가할 수 있게 한다. 진도 역시 등급 이름 하나가 아니라 수업·문제 ID를 기준으로 저장한다.

한 수업의 흐름: 쉬운 설명 → 예문과 음성 → 필요할 때 한글 발음 확인 → 연습 문제 → 정답·오답 해설 → 복습 등록.

주요 화면:

| 화면 | 역할 |
| --- | --- |
| 오늘의 공부 | 이어서 학습하기, 시험까지 남은 날을 기준으로 정한 오늘의 목표량, 오늘 복습할 항목 |
| 시험 일정 | 목표 시험의 접수 시작·마감일과 시험일, 시험까지 남은 날 확인 |
| 학습 과정 | 현재 제공 중인 등급의 목차와 진도. 추후 상위 등급 추가 |
| 수업 | 설명·예문·음성·한글 발음 보기 |
| 문제 풀이 | 선택지, 채점, 해설 |
| 복습 | 틀린 문제와 저장한 표현 다시 공부 |
| 로그인·계정 | 기록을 계정에 저장하고 새 기기에서 복원 |
| 설정 | 한글 발음·후리가나 표시, 알림 설정, 마지막 동기화 시각 |
| 관리자 페이지 | 수업·단어·문제·음성과 시험 일정을 검토하고 게시 |

한글 발음은 항상 표시·눌러서 표시·숨기기 중에서 선택할 수 있게 설계한다. 기본값은 **눌러서 표시**다. 문맥에 따라 읽기가 달라지는 표현은 자동 변환 결과를 그대로 보여주지 않고 검토한 발음 데이터를 사용한다. 기본 수업과 청해에는 검토한 음성 파일을 사용하고, 기기 음성 합성은 보조 읽어주기에 사용한다.

목표 시험일을 정하면 남은 날짜와 아직 배우지 않은 수업·복습 분량을 바탕으로 하루 목표량을 계산한다. 학습을 놓치거나 진도가 앞서면 남은 기간에 맞춰 목표량을 다시 계산한다. 하루 학습 시간은 필수 입력값으로 요구하지 않는다.

시험 일정에는 접수 시작일·마감일과 시험일을 함께 표시한다. 일정은 응시 지역과 회차에 따라 달라질 수 있으므로 관리자가 공식 공지로 확인한 날짜만 게시한다. 앱은 새 일정을 API로 받아 저장하고, 오프라인에서는 마지막으로 받은 일정을 보여준다. 수업·단어·문제도 관리자가 게시한 검수 자료를 내려받고 로컬에 보관한다. 시작에 필요한 자료는 첫 APK에 포함한다. 자료 내용이 바뀌면 앱 재설치 없이 새 버전을 받는다.

## 3. 코드 구성 원칙

화면 이동 라이브러리와 학습 기능 코드를 분리한다. Expo Router 화면 파일은 가능한 한 얇게 두고, 실제 학습 동작은 기능별 폴더에 모은다.

```text
src/app/               Expo Router 화면 경로
src/features/lesson/   수업 표시·학습 동작
src/features/quiz/     문제 풀이·채점
src/features/review/   오답·복습
src/shared/            공통 문장·버튼 컴포넌트
src/store/             Redux 설정
src/db/                기기 내 SQLite 접근 코드
src/api/               콘텐츠·일정·학습 동기화 API
src/content/           APK에 포함할 검수된 시작 자료
assets/audio/          첫 실행에 필요한 예문·청해 음성
server/                서버 DB·인증·API 구현 위치(제품 선택 후 확정)
admin/                 관리자 화면 구현 위치(제품 선택 후 확정)
```

`AGENTS.md`가 필요하다면 나중에 이 원칙 중 **AI가 매 작업에서 지켜야 할 규칙만** 별도로 적는다. 이 문서는 제품 기획의 기록이고, 라이브러리 선택의 근거는 `TECH_STACK.md`에 둔다.

## 4. 제작 순서와 확인 기준

1. **서버와 콘텐츠 운영:** 인증·DB·관리자 페이지·콘텐츠/일정 게시 API를 만들고 검수한 시작 자료를 게시한다.
2. **첫 학습 흐름 완성:** 입문 안내, 히라가나, 기초 문장 수업과 음성, 문제·해설, 로컬 진도·오답 저장을 구현한다.
3. **동기화와 출시 점검:** 서버 계정에 기록을 동기화하고, 오프라인 학습·재접속·새 기기 복원과 관리자 게시 후 앱 갱신을 실제 APK로 확인한다. **1~3을 마쳐야 첫 출시본이다.**
4. **콘텐츠 확장:** 같은 운영 구조로 가타카나, N5·N4·N3, 모의 연습을 추가하고 이후 N2·N1로 확장한다. 각 과정의 출시 전 제작 범위는 따로 확정한다.

첫 흐름의 완료 기준:

- 처음 배우는 사람이 설명만 읽고 첫 수업을 시작할 수 있다.
- 한글 발음이 기본적으로 숨겨지고 문장별로 표시·숨기기가 된다.
- 포함된 수업과 음성은 인터넷 없이 이용할 수 있다.
- 앱을 종료했다 다시 열어도 진도와 오답이 남는다.
- 같은 계정으로 새 기기에서 로그인하면 서버에 동기화된 진도와 오답이 복원된다.
- 관리자가 콘텐츠·시험 일정을 게시하면 APK 재설치 없이 앱에서 새 버전을 받는다.
- 문법·뜻·발음·음성·정답과 해설을 사람이 검토한다.

## 5. 확정 사항과 남은 결정

- **첫 배포:** 본인 안드로이드폰에 APK로 설치한다. 실제 서비스처럼 서버·관리자·로그인·오프라인 동기화까지 갖춘 뒤 설치한다.
- **학습 목표:** 목표 시험일을 기준으로 남은 기간과 학습 분량을 계산해 하루 목표량을 제시한다.
- **시험 일정과 콘텐츠:** 관리자가 검수·게시한 내용을 앱이 받아 갱신하고 오프라인용으로 보관한다.
- **남은 결정 — 학습 자료 제작 범위:** 첫 버전에 넣을 수업·단어·문제·해설을 어디까지 만들지, 예문·청해 음성을 직접 만들지 또는 사용 허락을 받은 자료를 쓸지 정한다.
- **남은 결정 — 서버 운영:** 호스팅·인증 제품, 비용 한도, 로그인 방식과 콘텐츠 운영 담당자를 정한다. 구체적인 저장 구조는 [데이터베이스 계획](DATABASE_PLAN.md)에 둔다.
