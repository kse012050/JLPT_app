# JLPT N3 학습 콘텐츠 데이터 제작 기준

## 목적과 범위

이 문서는 문자·어휘 자료를 만들며 확인한 방식을 문법·독해·청해 데이터 작업에 재사용하기 위한 기준이다. 목표는 앱으로 N3 시험을 준비할 수 있을 만큼 넓은 학습 범위와 실전형 연습을 제공하는 것이다. 자료 개수나 앱 문제 점수만으로 합격을 보장하지 않는다.

JLPT 운영 기관은 공식 어휘·한자·문법 목록을 공개하지 않는다. 등급별 참고 목록은 비공식 자료로 표시하고, 범위와 문제 유형은 [JLPT N3 문제 유형 안내](https://www.jlpt.jp/e/guideline/pdf/n3_e.pdf?mode=pc)와 [공식 예제·문제집](https://www.jlpt.jp/e/samples/sampleindex.html)에 대조한다. 공식 시험 문제를 앱 데이터로 무단 복제하지 않는다.

## 문자·어휘 작업에서 가져올 기준

| 항목 | 현재 구현·확인한 내용 | 다음 영역에 적용할 점 |
| --- | --- | --- |
| 학습 범위 | 중복을 제거한 어휘 2,994개: N3 1,690개, N4 630개, N5 674개 | N3 자료와 필요한 선행 N4·N5 자료를 함께 제시하되, 중복과 등급 분류를 확인한다. |
| 출처 | OpenJLPT 참고 자료와 별도 작성한 학습 항목을 사용하고 출처·라이선스를 기록 | 출처, 가공 방법, 사용 조건을 데이터와 문서에서 추적 가능하게 한다. |
| 한국어 설명 | 원자료 어휘 2,963개의 한국어 뜻에 교정 데이터를 반영 | 기계 번역은 초안으로 취급하고 학습 화면에 내기 전에 뜻과 맥락을 검토한다. |
| 예문 | 검수한 어휘 예문 27개 항목만 번역을 표시하며, 나머지 번역 초안은 학습 화면에서 숨김 | 미검수 번역을 완성된 해설처럼 표시하지 않는다. 문법·독해·청해에서는 예문과 문맥의 검수 범위를 넓힌다. |
| 연습 | 뜻·한자 읽기·표기 문제와 문맥·유의 표현·용법 문제를 제공 | 항목 암기 문제와 실제 시험 형식의 문맥 문제를 모두 만든다. |
| 검증 | 항목 수, 중복, 보기 수·정답, 화면 반영을 스크립트로 검사 | 자동 검사와 사람이 일본어·한국어를 읽는 검수를 함께 수행한다. |

어휘 뜻 교정 데이터가 있다고 해서 모든 일본어 읽기와 예문의 자연스러움이 독립적으로 검증된 것은 아니다. 새 영역에서도 **수록 수**, **한국어 검수 완료 수**, **실전형 문제 수**를 구분해 기록한다.

문자·어휘 모의고사는 2회, 회차당 25문항·30분의 앱 연습 자료다. 각 회차에 한자 읽기 5문항, 표기 5문항, 문맥 속 어휘 7문항, 바꿔 말하기 5문항, 용법 3문항을 넣었다. 읽기·표기 정답 20개는 N3 참고 어휘 데이터의 단어와 읽기에 연결해 확인한다. 문맥·바꿔 말하기·용법 문항은 별도로 작성했으며 문제 수와 난도는 공식 시험과 같다고 가정하지 않는다.

모의고사의 문제와 해설은 APK에 포함되어 인터넷 없이 동작한다. 공식 자료 페이지는 외부 링크이므로 인터넷이 필요하다. [JLPT 공식 사이트 정책](https://www.jlpt.jp/e/policy.html)에 따라 공식 문제·음성은 앱에 복제하지 않고 출처에서 직접 확인한다.

## 새 영역에서 유지할 데이터 구조

- **학습 항목:** 고유 ID, 등급, 출처와 이용 조건, 일본어 원문, 한국어 설명, 예문·번역, 검수 상태를 연결한다. 원자료와 한국어 교정본을 분리해 원자료 변경 시 누락을 검사한다.
- **문제:** 문제 유형, 지문 또는 음성 ID, 질문, 서로 다른 보기 4개, 정답 하나, 한국어 정답 근거와 오답 이유, 자체 작성 여부를 기록한다. 같은 문제가 학습 단원과 모의고사에 반복되면 점수 해석에 주의한다.
- **시험형 보기:** 일본어 이해를 평가하는 문항의 보기는 일본어로 작성하고, 한국어는 제출 후 해설에 사용한다. 선택지만 읽어도 정답을 알 수 있는 번역·품사·형태 차이는 검수 때 제거한다.
- **모의고사:** 회차 ID, 영역, 문항 수와 유형 분포, 연습 시간, 제출 시점, 응답·정답·점수를 관리한다. 연습 점수를 JLPT 환산 점수나 합격 판정으로 표시하지 않는다.
- **검수:** 스크립트로 구조·수량·누락을 확인한 뒤 일본어 문장, 한국어 해설, 복수 정답 가능성, 실제 기기 화면을 별도로 읽고 확인한다. 독해는 지문과 답의 근거를, 청해는 음성과 대본의 일치를 추가로 확인한다.

## 모든 영역에 공통으로 적용할 데이터 원칙

1. **학습 목표를 먼저 정한다.** 공식 N3 문제 유형과 예제를 살펴보고, 각 항목이 어떤 문제 해결에 필요한지 연결한다. 비공식 목록의 개수만 늘리는 작업은 완료 기준이 아니다.
2. **원문과 교정본을 분리한다.** 원자료의 ID·출처를 유지하고, 한국어 수정과 자체 제작 콘텐츠는 별도로 관리한다. 수정 이유와 검수 상태를 추적할 수 있게 한다.
3. **화면 설명은 한국어로 쓴다.** 일본어 원문·표현은 학습 대상으로 유지한다. 뜻, 접속 방법, 뉘앙스, 예문 번역, 정답·오답 해설은 자연스러운 한국어로 제공한다. 영어 원자료를 학습 설명의 대체물로 표시하지 않는다.
4. **일본어와 번역을 함께 검수한다.** 일본어가 자연스럽고 목표 표현의 용례에 맞는지 확인한 뒤 한국어 뜻을 맞춘다. 어색하거나 출처가 불명확한 항목은 수정하거나 제외한다.
5. **비슷한 항목을 비교한다.** 동일·유사 표현의 중복을 제거하고, 의미·접속·상황에 따른 차이를 설명한다. 같은 뜻으로 보이는 선택지가 동시에 정답이 되지 않도록 한다.
6. **학습과 시험 연습을 연결한다.** 설명 → 검수한 예문·자료 → 유형별 문제 → 한국어 해설 → 오답 복습 순서로 구성한다. 문제는 정답만 외워도 풀리는 반복 패턴을 피한다.
7. **검수 상태를 명시한다.** 초안, 검수 중, 게시 가능을 구분한다. 미검수 번역은 게시 가능한 학습 자료로 계산하지 않는다.
8. **출처와 이용 조건을 확인한다.** 공식 샘플은 문제 형식과 난도를 확인하는 기준으로 사용한다. 외부 문장·지문·음성은 사용 허락과 재배포 조건을 확인하고 출처를 기록한다.

## 문법 데이터 작업에 적용

현재 참고 자료에는 N3 문법 101개, N4 98개, N5 81개, 총 280개와 예문 837개가 있다. N3 문법 101개는 13개 학습 단원에 연결했고 각 항목에 한국어 뜻·접속 형태·설명·첫 예문 번역과 표현 복원 문제를 제공한다. 기존 자체 작성 문법 항목 12개는 복습 단원으로 유지했다. N4·N5는 한국어 뜻과 접속 형태를 참고 화면에서 제공한다. 유형별 자체 작성 연습 문제는 문법 형식 20개, 문장 배열 12개, 글의 흐름 12개다. 참고 자료의 나머지 예문 번역 초안은 검수 전이므로 표시하지 않는다.

문법 모의고사는 별도 자체 작성 문제 20개씩 2회, 회차당 25분으로 제공한다. 이 시간과 문항 수는 앱의 연습 기준이며 공식 N3 문법·독해 통합 시험과 같지 않다. 공식 예제와 2012·2018 공식 문제집은 [JLPT 공식 자료 페이지](https://www.jlpt.jp/e/samples/sampleindex.html)에서 직접 연다. 공식 문제와 음성은 앱에 복제하지 않는다.

- N3 표현과 필요한 N4·N5 기초를 정리하고 중복·유사 표현을 대조한다. 빠진 핵심 용법은 근거를 확인해 자체 작성 자료로 보완한다.
- 각 표현에 한국어 뜻, 정확한 접속 형태, 쓰는 상황, 제한·주의점, 유사 표현과의 차이, 검수한 일본어 예문과 한국어 번역을 제공한다.
- 예문과 해설의 용법이 일치하는지 검수한다. 자동 번역 문구나 영어 문구가 학습 화면에 남지 않도록 확인한다.
- [N3 공식 문제 유형](https://www.jlpt.jp/e/guideline/pdf/n3_e.pdf?mode=pc)에 맞춰 문장에 맞는 문법 형식 선택, 문장 배열, 글의 흐름에 맞는 표현 선택을 연습한다. 현재의 자체 작성 연습 문제는 유형을 익히기 위한 자료이며, 공식 예제와 시간제한 모의고사로 난도와 속도를 따로 확인한다.

## 독해 데이터 작업에 적용

- N3에서 다루는 짧은 글·중간 길이 글·긴 글·정보 검색 자료를 고르게 제공한다. 안내문, 이메일, 설명문 등 실제 읽기 상황을 포함한다.
- 지문은 일본어 원문, 출처 또는 자체 작성 여부, 길이·난도, 핵심 어휘·문법, 한국어 해설을 함께 관리한다. 필요한 경우 문단별 한국어 설명을 제공하되 문제를 풀기 전에 정답을 노출하지 않는다.
- 질문은 핵심 내용, 이유·관계, 글쓴이의 의도, 필요한 정보 찾기를 다루고, 오답 선택지가 왜 틀렸는지도 한국어로 설명한다.
- 지문·정답·해설이 서로 모순되지 않는지 사람이 확인한다. 문장만 바꾸고 같은 문제를 반복해 수를 늘리지 않는다.

## 청해 데이터 작업에 적용

- N3의 과제 이해, 요점 이해, 개요 이해, 발화 표현, 즉시 응답을 고르게 연습한다. 공식 문제 유형은 [N3 안내](https://www.jlpt.jp/e/guideline/pdf/n3_e.pdf?mode=pc)를 기준으로 확인한다.
- 각 항목에 검수한 일본어 음성, 대본, 한국어 해설, 정답 근거, 오답 이유를 연결한다. 속도·발음·잡음·음량을 실제 기기에서 확인한다.
- 실전 모드에서는 음성을 먼저 듣고 답하게 하며, 학습·복습 단계에서 대본과 번역을 열어 볼 수 있게 한다.
- 기기 음성 합성으로 읽은 문장과 사람이 검수한 청해 음성을 구분한다. 음성이나 대본을 사용할 권리도 확인한다.

## 게시 전 확인 기준

- 각 영역의 항목 수와 출처·검수 완료 수를 별도로 집계한다. 중복 ID, 빈 설명, 누락된 번역·음성, 잘못된 연결을 검사한다.
- 모든 문제에 유효한 정답이 하나만 있는지, 선택지와 한국어 해설이 지문·예문·음성과 일치하는지 확인한다.
- 학습 화면과 복습·진도 저장에서 실제 데이터가 표시되는지 웹과 안드로이드에서 확인한다.
- 공식 N3 예제 또는 허용된 모의 자료로 문제 유형과 난도를 비교하고, 시간제한 풀이 결과를 바탕으로 부족한 범위를 보완한다. 앱 자료의 양만으로 합격 가능성을 단정하지 않는다.
- 코드 변경이 있으면 프로젝트 규칙에 따라 `expo lint`와 `tsc --noEmit`을 실행한다.
